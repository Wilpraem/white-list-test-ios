# 📱 Проверка белых списков

Мобильное приложение для фоновой и ручной проверки доступности веб-ресурсов (выявление "белых списков" при блокировках мобильного интернета), разработанное на **React Native** с использованием **Expo**.

## 🚀 Возможности

- ⚡ Проверка белых списков по популярным российским и зарубежным доменам
- 🔍 Фоновый мониторинг состояния сети (с учетом VPN и WiFi)
- 🎨 Современный интерфейс с навигацией (Expo Router)
- ⚡ Оптимизированная производительность (React Native 0.81, Expo SDK 54)

## 💻 Развертывание и локальный запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Wilpraem/white-list-test-ios.git
cd white-list-test-ios
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите локальный сервер Expo:

```bash
npx expo start
```

### 🍎 Запуск на iOS (Mac + Simulator / iPhone)
Для запуска на iOS требуется Mac с установленным Xcode. Expo автоматически соберет проект и скачает зависимости (CocoaPods).

**В Симуляторе:**
```bash
npm run ios
# или
npx expo run:ios
```
*(При первом запуске скачивание может занять от 2 до 10 минут).*

**На реальном iPhone (через кабель):**
1. Сгенерируйте iOS-проект: 
   ```bash
   npx expo prebuild --platform ios --clean
   ```
2. Откройте проект в Xcode: 
   ```bash
   xed ios
   ```
3. Во вкладке **Signing & Capabilities** корневого проекта укажите свой аккаунт Apple ID (Team).
4. Выберите свой iPhone и нажмите **Play** (`Cmd + R`).

### 🤖 Запуск на Android

Для запуска на Android-эмуляторе или физическом устройстве:

```bash
npm run android
# или
npx expo run:android
```

## 🚀 Сборка и релиз через Expo Application Services (EAS)

Для облачной сборки (TestFlight, App Store, Google Play) используется EAS Build.

1. Установите EAS CLI и авторизуйтесь:
   ```bash
   npm install -g eas-cli
   eas login
   ```
2. **Сборка для iOS (TestFlight / App Store):**
   ```bash
   eas build --platform ios --profile production
   ```
3. **Сборка для Android (APK / AAB):**
   ```bash
   eas build --platform android --profile preview    # APK для тестов
   eas build --platform android --profile production # AAB для Google Play
   ```

## ⚠️ Важные ограничения iOS

Так как приложение использует фоновые задачи (`expo-background-fetch`), обратите внимание на специфику платформы Apple:
1. **Непредсказуемость Background Fetch**: На iOS интервал в `5 минут` — это лишь "пожелание". iOS сама решает (на основе ML), когда дать приложению проснуться в фоне.
2. **Лимит времени**: При пробуждении в фоне на iOS у приложения есть **всего ~30 секунд** на выполнение задачи. Текущая реализация (пинг 3-х сайтов) легко укладывается в этот лимит.
3. **Нет Foreground Service**: На Android фоновую работу можно сделать непрерывной с помощью закрепленного уведомления. На iOS такого механизма нет (за исключением навигаторов/музыки).
4. **Перезагрузка устройства**: Опция автозапуска (`startOnBoot`) работает только на Android. На iOS пользователь должен запустить приложение вручную после перезагрузки.
