# 📱 Проверка белых списков (iOS Edition)

Мобильное приложение для фоновой и ручной проверки доступности веб-ресурсов (выявление "белых списков" при блокировках мобильного интернета), разработанное на **React Native** с использованием **Expo**.

> ⚠️ **Внимание пользователям Android:** Данный форк адаптирован и задокументирован специально для iOS. Если у вас устройство на Android, пожалуйста, перейдите в **[Официальный репозиторий проекта](https://github.com/Aleksey-Kon/white-list-test)** для загрузки готового APK-файла.

## 📥 Как установить на iPhone (без джейлбрейка)

Поскольку приложения нет в App Store, вы можете установить его методом Sideloading (загрузка в обход магазина).

### Способ 1: Установка готового файла (Самый простой)
1. Перейдите в раздел **[Releases](../../releases/latest)** нашего репозитория и скачайте готовый файл `white-list-test.ipa`.
2. Установите `.ipa` файл на ваш iPhone одним из способов:
   - **[Sideloadly](https://sideloadly.io/)** (Рекомендуется) — бесплатная программа для Windows/Mac. Позволяет легко установить приложение через кабель, подписывая его вашим личным бесплатным Apple ID.
   - **AltStore** / **Scarlet** — популярные альтернативные магазины для установки `.ipa` файлов через ваш Apple ID.
   - **ESign** / **Bullfrog Assistant** — отлично подойдут, если у вас есть купленный сертификат разработчика или корпоративный сертификат.

### Способ 2: Самостоятельная компиляция проекта (Для разработчиков)
Если у вас есть Mac с установленным Xcode, вы можете собрать приложение сами:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Wilpraem/white-list-test-ios.git
   cd white-list-test-ios
   ```
2. Установите зависимости проекта:
   ```bash
   npm install
   ```
3. Сгенерируйте нативный iOS-проект (автоматически скачает и установит CocoaPods):
   ```bash
   npx expo prebuild --platform ios --clean
   ```
4. Откройте сгенерированный проект в Xcode:
   ```bash
   xed ios
   ```
5. В левом меню Xcode нажмите на корневой проект `testwhitelist`, перейдите на вкладку **Signing & Capabilities** и в поле **Team** выберите ваш личный Apple ID.
6. Подключите iPhone по кабелю, выберите его в верхней панели Xcode (вместо симулятора) и нажмите кнопку **Play** (`Cmd + R`).

## 🚀 Сборка через Expo Application Services (EAS)

Если вы хотите собрать приложение в облаке (например, для публикации в TestFlight или App Store):

1. Установите EAS CLI и авторизуйтесь в свой аккаунт Expo:
   ```bash
   npm install -g eas-cli
   eas login
   ```
2. Запустите облачную сборку:
   ```bash
   eas build --platform ios --profile production
   ```

## ⚠️ Важные ограничения iOS

Так как приложение использует фоновые задачи (`expo-background-fetch`), обратите внимание на специфику платформы Apple:
1. **Непредсказуемость Background Fetch**: На iOS интервал в `5 минут` — это лишь "пожелание". iOS сама решает (на основе машинного обучения и привычек пользователя), когда дать приложению проснуться в фоне.
2. **Лимит времени**: При пробуждении в фоне на iOS у приложения есть **всего ~30 секунд** на выполнение задачи. Текущая реализация (пинг 3-х сайтов) легко укладывается в этот лимит.
3. **Нет Foreground Service**: На Android фоновую работу можно сделать непрерывной с помощью закрепленного уведомления. На iOS такого механизма нет (за исключением навигаторов/музыки).
4. **Перезагрузка устройства**: Опция автозапуска (`startOnBoot`) работает только на Android. На iOS пользователь должен запустить приложение вручную после перезагрузки.
